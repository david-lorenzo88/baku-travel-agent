# Usability test kit — Baku Travel Planner (T046 / SC-006)

Five 20-minute sessions with people who have never seen the agent. Each tester plans a trip from
a scenario card — hotel, at least two activities, confirmation, PDF — while you watch without
helping.

| File | Use |
|---|---|
| [facilitator-guide.md](facilitator-guide.md) | Setup checklist, intro script, help rules, price table for checking totals |
| [tester-cards.md](tester-cards.md) | Five scenario cards with fictional holder details — one per tester |
| [observation-sheet.md](observation-sheet.md) | One copy per tester: timings, outcome, totals check, sticking points, 3 questions |
| [results.md](results.md) | Combine the five sheets and decide SC-006 |

**Pass rule**: all 5 testers complete hotel → confirmation → PDF without help (SC-006 is 90%).
**Budget**: about 50 Copilot Credits per session.
**Privacy**: testers use only the fictional details on their card.
