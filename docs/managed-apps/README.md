# Apps on Copilot Managed Runtime (built with Copilot Studio)

Besides agents, Copilot Studio can generate **apps** — interactive web apps with screens, data and
logic — from a natural-language description. They run on the **Copilot Managed Runtime**
(sometimes called "managed apps", after its admin settings and its `managedapps.cloud.microsoft`
address). In the **Masterclass at the Baku AI Summit (13 November 2026)**, David Lorenzo used it to build
the audience-voted hackathon idea — a Baku travel agent — as an app with its data in SharePoint,
alongside this repo's Copilot Studio agent. (Lee Stott built the same idea with Microsoft Foundry:
[leestott/AISummitHackBaku](https://github.com/leestott/AISummitHackBaku).)
